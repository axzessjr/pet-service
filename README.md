# Pawpal - ระบบแนะนำบริการสัตว์เลี้ยง 🐾

ยินดีต้อนรับสู่โปรเจกต์ **Pawpal**! ระบบนี้ถูกเขียนด้วย NestJS (สำหรับ Backend) และ React/Vite (สำหรับ Frontend)

## 🚀 วิธีการรันโปรเจกต์ในเครื่องตัวเอง

โปรเจกต์นี้แยกโฟลเดอร์ Frontend และ Backend ออกจากกัน ดังนั้นคุณต้องเปิด **Terminal 2 หน้าต่าง** เพื่อรันพร้อมกัน

*(หมายเหตุ: ต้องติดตั้ง Node.js และ npm ในเครื่องก่อนเริ่ม)*

### 1️⃣ การรัน Backend (NestJS)
เปิด Terminal หน้าต่างที่ 1 แล้วพิมพ์คำสั่ง:
```bash
cd backend
npm install
npm run start:dev
```
*Backend จะรันอยู่ที่ `http://localhost:3000`*

### 2️⃣ การรัน Frontend (React)
เปิด Terminal หน้าต่างที่ 2 แล้วพิมพ์คำสั่ง:
```bash
cd frontend
npm install
npm run dev
```
*Frontend จะรันอยู่ที่ `http://localhost:5173`*

### 3️⃣ เข้าใช้งานหน้าเว็บ
เมื่อรันทั้งสองคำสั่งเสร็จแล้ว ให้เปิดบราวเซอร์และเข้าไปที่:
👉 **[http://localhost:5173](http://localhost:5173)**

---

## 🏗️ โครงสร้างโปรเจกต์แบบเข้าใจง่าย

*   **`frontend/`**: หน้าเว็บทำด้วย React และ Vite (ใช้ Tailwind CSS ในการตกแต่ง)
*   **`backend/`**: ระบบหลังบ้านทำด้วย NestJS ซึ่งถูกแบ่งเป็นส่วนๆ (Modules) เพื่อให้จัดการง่าย:
    *   `CatalogModule`: จัดการข้อมูลบริการต่างๆ (เช่น อาบน้ำ, ตัดขน) และราคา
    *   `PetProfileModule`: จัดการข้อมูลผู้ใช้งานและสัตว์เลี้ยง
    *   `UsageReviewModule`: จัดการเรื่องการจองคิวและรีวิว (จะทำในอนาคต)
    *   `RecommendationModule`: เตรียมไว้สำหรับเชื่อมต่อกับระบบ AI แนะนำบริการ ที่เขียนด้วย Python (จะทำในอนาคต)

*(หมายเหตุ: ตอนนี้เรากำลังใช้ข้อมูลจำลอง (Mock Data) ใน Backend เพื่อให้ง่ายต่อการทดสอบก่อนต่อฐานข้อมูลจริง!)*
